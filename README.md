# ✨ Overview

**NGL LINK** is a modern anonymous messaging platform where users can create a personal message link and receive anonymous messages from anyone online.

People can:

* Create an account
* Share their unique link
* Receive anonymous messages
* Manage messages securely from their dashboard

This project focuses on:

* ⚡ Fast performance
* 🔒 Secure authentication
* 📱 Mobile responsiveness
* 🎨 Clean UI/UX
* ☁️ Cloud-based backend

---

# 🎯 Why This Project?

Social media users love anonymous interactions.
This project recreates that experience while also serving as a **full-stack learning project** showcasing:

* Authentication Systems

* Cloud Database

* Responsive UI Design

# 📦 Installation

# 1️⃣ Clone Repository

```bash
git clone https://github.com/yourusername/ngl-link.git
```

---

# 2️⃣ Navigate Into Folder

```bash
cd ngl-link
```

---

# 3️⃣ Install Dependencies

```bash
npm install
```

---

# 4️⃣ Setup Environment Variables

Create `.env`

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

---

# 5️⃣ Run Development Server

```bash
npm run dev
```
